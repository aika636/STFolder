# STFolder

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern): собирает
плавающие кнопки других расширений в одну маленькую перетаскиваемую «папку». Тап по
папке раскрывает сетку с кнопками, тап по кнопке срабатывает как по оригиналу. Работает
на телефоне и на компьютере — пальцем, мышью и с клавиатуры.

Расширение не участвует в чате и не обращается к LLM — только к интерфейсу SillyTavern.

## Возможности

- Находит плавающие кнопки любых расширений сама — по общим признакам, без списка
  известных расширений.
- Вид папки: 10 иконок, 4 стиля, размер 32–72 px. Цвета берутся из темы таверны и
  меняются вместе с ней.
- Долгое нажатие на папку — режим «Упорядочить»: кнопки можно переставлять, вытаскивать
  из папки на экран и возвращать обратно.
- Кнопки, которые не встают в папку как есть, показываются копией — нажатие на неё
  срабатывает как по оригиналу.
- «Добавить вручную» — для кнопки, которую папка не нашла сама.
- Пункт «Папка кнопок» в меню волшебной палочки и команда `/stfolder`
  (`open`, `close`, `arrange`, `pick`, `scan`, `home`).

## Установка

В SillyTavern: **Extensions → Install extension**, вставить ссылку на этот репозиторий:

```
https://github.com/aika636/STFolder
```

После установки — перезагрузить страницу таверны.

## Разработка

Без сборки: обычные ES-модули и CSS. Тесты — под Node:

```
node tests/run.mjs
```
